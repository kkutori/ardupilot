# Copter Ship Landing 脚本说明

## 概述
`copter_ship_landing.lua` 脚本为 ArduCopter 提供了在移动平台（如船舶）上起飞和降落的功能。该脚本允许多旋翼飞行器在 RTL（Return to Launch）模式下跟随移动的船舶，并在满足条件时安全降落到船上。

## 工作原理
脚本通过以下方式实现船舶降落功能：

1. **船舶跟踪**：当飞行器处于 RTL 模式时，脚本会自动切换到 GUIDED 模式，并在安全高度跟随船舶
2. **降落触发**：通过降低油门摇杆位置来触发降落程序
3. **分阶段降落**：
   - **跟随阶段 (STAGE_FOLLOW)**：在设定的偏移位置和高度跟随船舶
   - **爬升阶段 (STAGE_CLIMB)**：如果当前高度低于 RTL_ALT，先爬升到指定高度
   - **接近阶段 (STAGE_APPROACH)**：飞到船舶正上方的指定高度
   - **降落阶段 (STAGE_LAND)**：垂直降落到船舶上
4. **自动解除武装**：成功降落后自动解除武装

## 参数说明

### 脚本专用参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `SHIP_ENABLE` | 0 | 启用/禁用船舶降落系统<br>0: 禁用, 1: 启用 |
| `SHIP_AUTO_OFS` | 0 | 自动偏移计算触发器<br>0: 禁用, 1: 触发（触发后会自动重置为0） |
| `SHIP_FL_X` | -20 | 飞行器相对于船舶的X轴偏移（米）<br>正值：飞行器在船舶前方，负值：在船舶后方 |
| `SHIP_FL_Y` | 0 | 飞行器相对于船舶的Y轴偏移（米）<br>正值：飞行器在船舶右侧，负值：在船舶左侧 |
| `SHIP_FL_Z` | -30 | 飞行器相对于船舶的高度偏移（米）<br>正值：飞行器始终在船舶上方，负值：同上（注：实际代码中为负值表示上方） |

### 相关系统参数

脚本会在启动时自动检查并配置以下关键系统参数以确保正常工作：

- **`FOLL_ENABLE = 1`**：启用跟随模式功能
- **`FOLL_OFS_TYPE = 1`**：设置跟随偏移类型为"位置偏移"
- **`FOLL_ALT_TYPE = 0`**：设置跟随高度类型为"绝对高度"

**自动配置机制**：
脚本在加载时会调用 `check_parameters()` 函数，该函数会：
1. 检查上述三个参数的当前值
2. 如果参数值与期望值不同（差异大于0.001），则自动将其设置为正确的值
3. 保存参数到持久存储中
4. 通过地面站发送信息通知用户参数已被修改

这种自动配置确保了脚本能够正常工作，无需用户手动设置这些底层参数。

## 使用方法

### 1. 准备工作
- 确保已配置好跟随目标（如通过 LANDING_TARGET MAVLink 消息提供船舶位置）
- 飞行器需要能够接收船舶的位置和速度信息

### 2. 启用脚本
1. 将 `SHIP_ENABLE` 参数设置为 `1`
2. 根据需要调整 `SHIP_FL_X`、`SHIP_FL_Y`、`SHIP_FL_Z` 参数以设置合适的跟随位置

### 3. 操作流程
1. **进入 RTL 模式**：飞行器会自动切换到 GUIDED 模式并开始跟随船舶
2. **控制降落阶段**：
   - **油门高位 (40%-100%)**：保持在跟随阶段
   - **油门中位 (10%-40%)**：如果高度足够，直接进入接近阶段；如果高度不足，先进入爬升阶段
   - **油门低位 (0%-10%)**：开始降落程序
3. **监控降落过程**：
   - 飞行器会先爬升到 `RTL_ALT` 高度（如果需要）
   - 然后飞到船舶正上方
   - 最后垂直降落
4. **中断降落**：在任何阶段将油门推到中位或高位都可以中断降落并返回到相应阶段

### 4. 自动偏移计算
如果不确定合适的偏移值，可以使用自动偏移计算功能：
1. 确保飞行器已解锁并在空中
2. 将 `SHIP_AUTO_OFS` 设置为 `1`
3. 脚本会自动计算当前飞行器位置相对于船舶的偏移，并设置到 `FOLL_OFS_X`、`FOLL_OFS_Y`、`FOLL_OFS_Z` 参数中

## SITL 仿真使用步骤

### 1. 启动 SITL 仿真环境

在 ArduPilot 项目根目录下执行以下命令启动 Copter SITL 仿真：

```bash
sim_vehicle.py -v ArduCopter --console --map -w
```

参数说明：
- `-v ArduCopter`：指定载具类型为多旋翼
- `--console`：打开 MAVProxy 控制台
- `--map`：显示地图界面
- `-w`：清除之前的参数设置（首次运行时使用）

### 2. 配置船舶仿真参数

在 MAVProxy 控制台中依次输入以下命令：

```bash
# 启用船舶仿真
param set SIM_SHIP_ENABLE 1

# 启用脚本功能
param set SCR_ENABLE 1

# 增加脚本堆内存（可选，但推荐）
param ftp
param set SCR_HEAP_SIZE 100000

# 重启以应用参数
reboot
```

### 3. 配置船舶降落脚本参数

重启后，在控制台中设置脚本相关参数：

```bash
# 启用船舶降落功能
param set SHIP_ENABLE 1

# 如果需要自动计算偏移，可以设置（在飞行前设置）
param set SHIP_AUTO_OFS 1
```

### 4. 执行船舶降落任务

```bash
# 切换到 GUIDED 模式
mode guided

# 解锁电机
arm throttle

# 设置初始油门位置
rc 3 1500

# 起飞到40米高度
takeoff 40

# 等待飞行器稳定后，切换到 RTL 模式开始船舶跟随
mode rtl

# 降低油门触发降落（油门值1100对应低位）
rc 3 1100
```

### 5. 降落控制说明

- **油门控制**：
  - `rc 3 1900`（高位）：保持在跟随阶段
  - `rc 3 1300`（中位）：进入接近阶段（如果高度足够）或爬升阶段
  - `rc 3 1100`（低位）：开始最终降落

- **中断降落**：在任何阶段将油门推回到中位或高位即可中断降落并返回到相应阶段

### 6. 验证降落成功

成功降落后，飞行器会：
1. 自动解除武装
2. 在地面站显示 "Motors disarmed successfully" 信息
3. 由于降落在移动的船舶上，飞行器会保持与船舶相同的地面速度

### 7. 其他可配置参数

```bash
# 可选：设置船舶速度（默认3m/s，可调整为8m/s）
param set SIM_SHIP_SPEED 8

# 可选：调整飞行速度和角度限制以适应船舶降落
param set WPNAV_SPEED 2000    # 航点导航速度 20m/s
param set ANGLE_MAX 4000      # 最大倾斜角度 40度
```

## 安全特性

- **授权检查**：只有在检测到有效的船舶信标时才允许解锁
- **稳定检查**：在关键阶段（如到达指定高度、在船舶正上方）会检查稳定性，确保持续3-4秒稳定后才进入下一阶段
- **速度限制**：根据距离自动调整最大修正速度，远距离时速度较快，近距离时速度较慢以确保精度
- **错误处理**：脚本包含错误处理机制，即使出现内部错误也不会完全停止运行

## 注意事项

- 确保 `RTL_ALT` 参数设置合理，通常建议设置为30米（3000厘米）以上
- 船舶速度不宜过快，建议在脚本支持的速度范围内（默认5m/s，最大建议不超过10m/s）
- 在实际使用前，建议在仿真环境中充分测试
- 降落过程中保持对飞行器的监控，必要时可通过遥控器接管控制
